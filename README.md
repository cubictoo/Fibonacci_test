# Fibonacci Calculator and Tests

This project contains a Python script to calculate Fibonacci numbers and a set of unit tests to verify its correctness.

## `fibonacci.py`

This script defines a function `calculate_fibonacci(n)` that iteratively calculates the nth Fibonacci number.

### Running the script

You can run the script directly to see an example calculation for F(13):

```bash
python fibonacci.py
```

## `test_fibonacci.py`

This file contains unit tests for the `calculate_fibonacci` function. It uses Python's `unittest` module.

### Running the tests

To run the tests, execute the following command in your terminal:

```bash
python -m unittest test_fibonacci.py
```
